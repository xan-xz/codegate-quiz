# CodeGate

Нужен Node.js 24 или новее. Зависимостей нет.

Запуск: `npm start`. Откройте http://localhost:3000, панель: http://localhost:3000/admin.
При запуске сервер печатает случайный ключ администратора. Для постоянного ключа задайте ADMIN_KEY через переменные окружения. Не передавайте его участникам. Генерируйте для них отдельные одноразовые коды в панели.

Одноразовое погашение кода атомарно в SQLite. Сессия хранится в HttpOnly cookie и связана с идентификатором браузера. Повторное погашение кода с другого устройства отклоняется. Это ограничение сессии, а не достоверная идентификация физического устройства: намеренное копирование cookie и хранилища браузера не исключено. IP не используется: общий Wi-Fi не означает одного человека.

После начала теста visibilitychange, blur и уход со страницы блокируют попытку. Срабатывающие клавиши скриншота также вызывают бан. ОС может сделать снимок без события для сайта; мобильные скриншоты, камеру и второй экран обнаружить нельзя. Пользователь с инструментами разработчика может отключить клиентские события. Это демонстрационный контроль дисциплины, не защищённая система прокторинга. Потеря фокуса из-за уведомления может дать ложное срабатывание. При потере связи интерфейс блокируется, событие отправляется при следующем открытии. Выдайте новый код для повторной попытки.

## Railway

Разместите содержимое этой папки в отдельном Git-репозитории, подключите его к Railway. Используйте Dockerfile, задайте ADMIN_KEY (длинное случайное значение), HOST=0.0.0.0, NODE_ENV=production и DATA_DIR=/data. Подключите постоянный volume к /data. Используйте один экземпляр приложения и HTTPS. Без volume данные пропадут при пересоздании контейнера. Не включайте общий доступ к терминалу или логам с ключом. На Vercel этот сервер с локальной SQLite не подходит.

Проверки: `npm test`.
